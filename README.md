# Document Content Search & Retrieval System

## Project Overview

The **Document Content Search & Retrieval System** is a Python-based project that aims to help users find information across multiple documents quickly and easily.

Instead of opening documents one by one, users will be able to search for keywords or phrases across multiple `.txt` and `.docx` files. The system will display matching documents and provide useful information about the search results.

The project will primarily focus on **functional programming**, file handling, and text processing.

## Problem Statement

Searching for specific information in multiple documents manually can be time-consuming, especially when the documents contain large amounts of text. This project aims to simplify the process by allowing users to search document contents from a single terminal-based application.

## Objectives

* Search for keywords and phrases inside multiple documents.
* Support both text files (`.txt`) and Microsoft Word documents (`.docx`).
* Display matching documents and keyword occurrence counts.
* Apply functional programming concepts to text processing and searching.
* Provide a simple and user-friendly terminal interface.

## Planned Features

* Keyword and phrase searching.
* Case-insensitive searches.
* Searching with multiple keywords using AND/OR conditions.
* Counting keyword occurrences.
* Ranking search results by relevance.
* Previewing relevant text from matching documents.
* Filtering searches by file type.
* Maintaining a search history.

*These features are planned and may be refined during development.*

## Technologies

* **Interface:** Command-Line Interface (CLI)
* **Version Control:** Git and GitHub
